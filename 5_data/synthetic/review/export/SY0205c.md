## Gold: summary (F1)

**abstract**
- The project manager opened the conceptual design meeting, welcomed back the user interface designer, and reported that the operator's brand guide had arrived and been forwarded.
- The marketing expert reported that she had sent the competitor screenshots and that visitor statistics show Spanish and Italian speakers make up about a fifth of foreign visitors. The team decided to launch with English, German and French, with layouts that leave room for longer strings.
- The industrial designer presented the step-by-step unlock flow, timed at about twenty-two seconds on QR docks and about twenty-eight seconds on keypad docks, and reported that the one-time keypad code is valid for two minutes.
- The user interface designer presented the map mock-up with numbered and shaped pins, a bikes/slots toggle, a bottom sheet and a permanent scan-to-unlock button, and reported that his technical functions list is finished. The team agreed on opt-in low-bike alerts for favourite docks.
- The project manager took on checking the live data feed cost, which the industrial designer had offered to do. The unlock timing test was moved from the user interface designer to the marketing expert because of his workload.

**actions**
- The marketing expert will run an unlock timing test with five people from her commuter panel, including some tourists if possible. The task was reassigned from the user interface designer.
- The user interface designer will send the marketing expert the clickable prototype when it is ready.
- The user interface designer will revise the mock-up with the bikes/slots toggle, the keypad code countdown and the alert settings for the detailed design meeting.
- The user interface designer will design the layouts with room for longer translated strings.
- The marketing expert will write the guest pass pre-authorisation explanation text in English, German and French.
- The project manager will find out through the account manager what the operator's live data feed costs and whether it affects the 120,000 euro budget.
- The industrial designer will get the operator's API documentation for the unlock calls.
- The project manager will circulate the minutes.

**decisions**
- The app will launch with English, German and French, and the layouts will leave room for longer strings so that Spanish and Italian can be added later.
- The keypad code fallback will show a countdown, because the code is valid for two minutes.
- The map will be full screen with numbered, shaped pins in the brand teal, grey for empty, and a toggle between bikes and free slots.
- Tapping a pin opens a bottom sheet with the station name, bikes, slots and walking time.
- A large orange scan-to-unlock button will always be visible, so the camera is one tap from opening the app.
- Home and work favourites will appear as shortcut chips above the map.
- Low-bike alerts will be opt-in, per favourite dock, within a time window the user chooses.
- A short explanation screen about the 150 euro pre-authorisation will be shown before the card form in the guest pass flow.

**problems**
- The cost of the operator's live data feed is still unknown and may affect the budget and the map refresh rate.
- The unlock timings were measured only by the industrial designer, and the test with real users cannot start until the prototype is clickable in about a week.
- Keypad docks take about twenty-eight seconds, close to the thirty-second target.
- The home-screen widget proposal was left open pending its cost on two platforms.
- The marketing expert still thinks that leaving Spanish and Italian out at launch is a mistake for the summer season.
- The user interface designer's workload is high.
