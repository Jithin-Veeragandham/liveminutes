## Gold: summary (F1)

**abstract**
- The project manager opened the conceptual design meeting, confirmed he had sent the previous minutes, and recapped the decisions from the functional design meeting.
- The industrial designer reported the supplier quote: 1.80 euros per cup and lid for the 350 ml size and 1.65 euros for the 250 ml size, including about five cents for laser etching, well under the three-euro target, with the second mould as a one-off tooling cost.
- The marketing expert reported that the café chains accept 250 ml and 350 ml and want a full deposit refund even when a cup is returned without its lid; the team kept two sizes and agreed on the full refund.
- The user interface designer presented the updated return flow with scanning and manual code entry, and the team agreed to use a data matrix code readable by the existing 2D till scanners.
- On the concept, the team agreed on a tapered, stackable cup with a stacking ridge, one charcoal scheme-wide colour with a scheme logo and an embossed return line instead of chain branding, and a push-fit lid with a sip hole, and decided it was now time for physical mock-ups.

**actions**
- The industrial designer will build mock-ups of both cup sizes with the lid for the next meeting.
- The industrial designer will get a supplier quote for spare lids sold separately.
- The user interface designer will design the markings on the cup base and side (code position and return text).
- The user interface designer will add the manual code entry step properly to the return flow.
- The marketing expert will find out which scanners the café chains use; this was first given to the user interface designer.
- The marketing expert will check the charcoal scheme colour with the café chains.
- The project manager will write up the minutes and send them to the team.

**decisions**
- The cup stays at two sizes, 250 ml and 350 ml; a 450 ml size will not be pursued.
- Customers get the full two-euro deposit back even if the cup is returned without its lid, for now.
- The code on the base will be a laser-etched data matrix code readable by the cafés' existing 2D till scanners, with no extra hardware; baristas can type the code in if a scan fails.
- The cup will be slightly tapered so cups stack, with a ridge near the bottom to stop jamming, and both sizes share the same top diameter.
- All cups will be one neutral charcoal colour with a scheme logo and an embossed 'return to any café' line, with no chain-specific branding.
- The lid will be a push-fit polypropylene lid with a sip hole and no sliding closure.

**problems**
- It is not yet known whether all café chains have 2D scanners; some may only have older line scanners.
- The cost of lids lost through full refunds without lids needs to be monitored, and nobody was assigned to track it.
- The café chains have not yet been consulted on the single charcoal colour without their own branding.
