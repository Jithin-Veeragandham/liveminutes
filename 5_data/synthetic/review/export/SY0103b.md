## Gold: summary (F1)

**abstract**
- The project manager opened the functional design meeting, noted that the industrial designer was absent through illness so no cost breakdown was available, and recapped the kick-off decisions on on-device recognition, a wake word, a backup button and short spoken confirmations.
- The user interface designer presented the voice interaction: a fixed command set of set, stop, how long left, cancel and add a minute, with very short spoken confirmations preceded by the wake word.
- On multiple timers, the team settled on two timers addressed by number ('timer one', 'timer two'), with the timer announcing which one has finished; this replaced an earlier plan in the same meeting for three user-named timers, which was revised because free names break the fixed command set and users reported forgetting names and confusing timers.
- The marketing expert reported that users mainly complain about inaudible alarms and greasy buttons, and that about half of those asked would pay 25 euros once the hands-free feature was explained, especially as a gift; the team agreed to position the product as a kitchen gadget and to have a loud alarm that grows louder.
- From the marketing expert's candidate names, Kiko was chosen as the working wake word, while the user interface designer's idea of a small two-digit display and the power question were deferred until the industrial designer's cost breakdown is available.

**actions**
- The project manager will email the industrial designer with the minutes, tell him about the switch to two numbered timers and ask him to check that the speech chip can handle the command set (originally offered by the marketing expert).
- The industrial designer will check the speech chip against the command set and complete the cost breakdown and the battery versus mains power question for the next meeting.
- The user interface designer will write up the full command list and confirmation phrases for two timers.
- The user interface designer will test the wake word Kiko against everyday kitchen phrases for false triggers.
- The marketing expert will research existing voice-controlled timers and their prices.

**decisions**
- The timer will support two timers addressed by number ('timer one', 'timer two'), not three user-named timers.
- When a timer finishes it will announce which timer is done before the alarm sounds.
- The command set is set, stop, how long left, cancel and add a minute, with short spoken confirmations.
- The alarm will be loud and will get louder if nobody stops it.
- Kiko is the working wake word; Pepper was rejected because it is a word said while cooking.
- The product will be marketed as a hands-free kitchen gadget, including as a gift, rather than as an ordinary timer.

**problems**
- Battery versus mains power remains undecided until the industrial designer's input is available.
- The cost breakdown is still missing, so it is not known whether the components fit within 12.50 euros.
- It is not yet confirmed that the speech chip can handle the command set for two timers.
- A small two-digit display was proposed but parked pending cost figures.
- Willingness to pay 25 euros is only partial: most people would not pay that for a normal timer.
