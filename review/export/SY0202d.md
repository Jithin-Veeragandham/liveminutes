## Gold: summary (F1)

**abstract**
- The project manager opened the detailed design meeting and explained that the user interface designer was absent at a conference but had emailed her final screens. The industrial designer presented the foam-board mock-up at the real accessible heights. Because a nineteen-inch screen would rise above the 120 cm reach limit, the team chose a seventeen-inch screen over the fifteen-inch one. The industrial designer reported on text-to-speech, and the team chose an embedded PC board with a licensed built-in engine for better voice quality. The project manager presented the user interface designer's screens, which cover the barcode fallback, the audio script and the optional print button. The marketing expert evaluated the design against seven criteria from the library services requirements, the project manager reported an updated cost of about 3,410 euros per unit, and the team rejected an LED ring around the help button.

**actions**
- The marketing expert will find out what it would cost to RFID-tag the stock in the four barcode-only branches, using the tagging contractor's rates from library services, by the end of next week. The project manager first took this task himself.
- The user interface designer, who was absent, will rework the screen layouts for the seventeen-inch screen and send the final screens to library services for sign-off.
- The project manager will brief the user interface designer on Monday about the screen size decision.
- The industrial designer will write up the component specification (board, text-to-speech engine, screen) for the final report by Friday.
- The project manager will write the final report with the cost breakdown and circulate it.

**decisions**
- The kiosk will have a seventeen-inch screen instead of fifteen inches, which keeps the top edge at about 116 cm, within the 120 cm reach limit.
- The kiosk will use an embedded PC board that comes with a licensed text-to-speech engine, adding about 60 euros.
- The production cost is now about 3,410 euros per unit, under the 4,000-euro target, and the selling price stays at about 6,500 euros.
- No LED ring will be added around the help button in this design.

**problems**
- The cost of RFID-tagging the stock in the four barcode-only branches is still unknown until the marketing expert gets the contractor's rates.
- The seventeen-inch screen was decided without the user interface designer, who had wanted nineteen inches.
- Ease of use has not yet been checked with the seventeen-inch screen layouts.
